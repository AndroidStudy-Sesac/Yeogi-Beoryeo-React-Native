# Pretendard

기존 Android 앱 v1.1.0의 Pretendard 글꼴을 변경 없이 사용합니다. 기준 커밋은 `b3b7db10f29c8c4d6dfc70a77f446ed0a3f2bb56`이며, 원본 경로는 `common/src/main/res/font`입니다.

SIL Open Font License 1.1을 적용합니다. 저작권 고지와 전체 이용 조건은 함께 보관한 [LICENSE](LICENSE)에서 확인할 수 있습니다.

Expo Font config plugin으로 Android와 iOS 앱에 글꼴을 포함합니다. 화면에서는 각 파일의 PostScript 이름인 `Pretendard-Regular`, `Pretendard-Medium`, `Pretendard-SemiBold`, `Pretendard-Bold`, `Pretendard-ExtraBold`를 사용합니다.
